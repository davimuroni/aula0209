# Aula 0209 - Integração Contínua

## Projeto

Aplicação simples desenvolvida para a prática de Integração Contínua (CI), utilizando Node.js, Express, Jest e Docker.

## Testes

Os testes automatizados são executados utilizando o Jest.

## Integração Contínua

A Integração Contínua (CI) é útil em empresas para automatizar a execução de testes sempre que novas alterações são enviadas ao projeto. Dessa forma, possíveis erros podem ser identificados rapidamente antes que o código seja utilizado em produção. Essa abordagem é especialmente importante em equipes que trabalham em conjunto, pois aumenta a qualidade do software, reduz problemas e facilita a entrega de novas funcionalidades.

## GitHub Actions

O projeto utiliza GitHub Actions para executar automaticamente os testes por meio de um pipeline de CI a cada alteração enviada ao repositório.
